# Tester

Приложение для тестов по IT-курсам. Вопросы хранятся в JSON-файлах курсов, приложение их импортирует и ведёт прогресс: тренировка, работа над ошибками, интервальное повторение, экзамен с таймером, статистика по темам. Работает в браузере на ПК и телефоне. Данные лежат на устройстве, а после входа синхронизируются между устройствами через Supabase.

Опубликовано на GitHub Pages: https://evgenmak-coder.github.io/tester/ — сайт открывается с телефона и ставится на главный экран как приложение.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется на http://127.0.0.1:5180.

Без настроек приложение хранит всё только в браузере.

## Синхронизация через Supabase

Приложение остаётся рабочим без сети и без входа: все действия сразу пишутся на устройство, а обмен с облаком идёт в фоне — при входе, после изменений, при возврате в приложение. Если одну запись изменили на двух устройствах, остаётся более поздняя.

1. Скопируй `.env.example` в `.env.local`: там адрес проекта и публичный ключ.
2. Добавь в `.env.local` личный токен `SUPABASE_ACCESS_TOKEN` (Account → Access Tokens) и выполни `npm run migrate` — скрипт применит новые файлы из `supabase/migrations`. Без токена файл можно выполнить вручную в SQL Editor.
3. Заведи пользователя: Authentication → Users → Add user, почта и пароль. Вход — в приложении, на странице «Настройки».

Все таблицы закрыты RLS: каждый видит только свои строки, без входа не видно ничего, поэтому публичный ключ можно хранить в собранном сайте. Токен доступа — нельзя: все файлы `.env*`, кроме `.env.example`, исключены из git.

## Курсы

Курс — JSON-файл с темами и вопросами. У каждого вопроса есть уровень: базовый, средний или продвинутый; на странице курса уровни переключаются вкладками. Формат, правила и образец запроса для ИИ описаны в `docs/FORMAT.md`. Готовые файлы лежат в `courses/`: `linux.json` — рабочий курс, `linux-demo.json` — демо.

Файлы из `courses/` попадают в каталог внутри приложения: курс добавляется одной кнопкой, а после изменения файла в каталоге появляется кнопка «Обновить». Свой файл загружается на странице «Импорт». Повторный импорт файла с тем же `course.id` обновляет курс и сохраняет прогресс по вопросам с прежними `id`.

## Деплой

`.github/workflows/deploy.yml` прогоняет тесты, собирает сайт и публикует его на GitHub Pages при каждом push в `main`. Адрес и публичный ключ Supabase берутся из секретов репозитория `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

## Команды

- `npm run test` — тесты формата, набора вопросов, повторения и сценариев
- `npm run build` — проверка типов и сборка в `dist/`
- `npm run migrate` — применить новые миграции к базе; `npm run migrate -- --status` только показывает, что выполнено

## Устройство

- `src/quiz` — правила без интерфейса: формат курса (`format.ts`), сбор и подсчёт теста (`session.ts`), интервальное повторение (`srs.ts`), статистика (`stats.ts`)
- `src/data` — хранилище: интерфейс `DataStore`, реализация на localStorage, сценарии в `actions.ts`; синхронизация: правила слияния (`merge.ts`), один обмен с облаком (`sync.ts`), запросы к Supabase (`cloud.ts`), запуск и вход (`syncRunner.ts`)
- `src/features` — экраны: курсы, курс, прохождение и результат, импорт, настройки
