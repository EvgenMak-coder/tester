# Что такое скрипт

Скрипт — это текстовый файл с командами. Всё, что вы набираете в терминале по одной строке, можно записать в файл и выполнять одной командой. Так автоматизируют всё повторяющееся: резервное копирование, развёртывание, проверки.

Вот самый короткий скрипт:

```
#!/bin/bash
# Приветствие
echo "Привет, мир"
```

# Первая строка

Строка `#!/bin/bash` называется **шебанг**. Она сообщает системе, какой программе передать этот файл для выполнения. Без неё система будет гадать, и скрипт может выполниться другой оболочкой с другим поведением.

Шебанг должен стоять в самой первой строке, с первого символа.

# Комментарии

Всё от знака `#` до конца строки — комментарий: оболочка его пропускает. Комментарии пишут для людей, в том числе для себя через полгода. Хороший комментарий объясняет не что делает строка, а зачем.

# Запуск

Есть два способа запустить скрипт.

```
bash hello.sh
```

Здесь файл передаётся оболочке как аргумент. Права на исполнение не нужны: `bash` просто читает его.

```
chmod +x hello.sh
./hello.sh
```

Здесь файл запускается как программа. Для этого ему нужно право на исполнение, а путь должен быть указан явно: текущего каталога в `PATH` нет, поэтому просто `hello.sh` не сработает.

# Переменные

```
name=Anna
echo "Привет, $name"
```

Переменная создаётся присваиванием. Правило одно, и о него спотыкаются все: **вокруг знака равенства не должно быть пробелов**. Запись `name = Anna` оболочка поймёт как запуск команды `name` с аргументами.

Чтобы получить значение, перед именем ставят `$`. При присваивании знак доллара не нужен.

Результат команды можно сохранить в переменную:

```
today=$(date +%F)
echo "Сегодня $today"
```

# Аргументы

Скрипту можно передать данные при запуске, как любой команде:

```
./deploy.sh web production
```

Внутри скрипта они доступны через особые переменные:

- `$1`, `$2` и так далее — аргументы по порядку: здесь `web` и `production`;
- `$0` — имя самого скрипта;
- `$#` — число переданных аргументов.

```
#!/bin/bash
echo "Скрипт: $0"
echo "Сервер: $1, окружение: $2"
echo "Всего аргументов: $#"
```

# Условие: if

```
if [ $# -lt 1 ]; then
  echo "Укажите имя сервера"
  exit 1
fi
```

Конструкция читается так: если условие в квадратных скобках истинно, выполнить команды между `then` и `fi`. Пробелы внутри скобок обязательны.

Закрывающее слово — `fi`, то есть `if` наоборот. Для второй ветки есть `else`:

```
if [ "$1" = "production" ]; then
  echo "Осторожно: рабочий сервер"
else
  echo "Тестовый сервер"
fi
```

# Цикл: for

```
for f in a b c; do
  echo "$f"
done
```

Цикл по очереди кладёт в переменную каждое слово из списка и выполняет команды между `do` и `done`. Этот пример выведет три строки.

Чаще всего перебирают файлы:

```
for f in *.log; do
  echo "Обрабатываю $f"
done
```

# Ввод с клавиатуры: read

```
read -p "Продолжить? (y/n) " answer
if [ "$answer" = "y" ]; then
  echo "Продолжаем"
fi
```

`read` останавливает скрипт, ждёт, пока пользователь введёт строку и нажмёт Enter, и записывает введённое в переменную. Ключ `-p` выводит приглашение.

# Код завершения: exit

Каждая команда, завершаясь, возвращает число: ноль означает успех, любое другое — ошибку. Скрипт — тоже команда, и свой код он задаёт через `exit`:

```
exit 0
exit 1
```

`exit` немедленно завершает скрипт. `exit 1` сообщает тому, кто запустил скрипт, что работа не удалась. По этому числу планировщик, другой скрипт или система развёртывания понимают, продолжать ли дальше.

Если `exit` не написан, скрипт вернёт код своей последней команды.

# Коротко

- Скрипт — файл с командами; первая строка — `#!/bin/bash`.
- Комментарий начинается с `#`.
- Запуск: `bash файл` или `chmod +x файл` и `./файл`.
- Присваивание без пробелов: `name=Anna`; чтение — `$name`.
- `$1`, `$2` — аргументы, `$#` — их число, `$0` — имя скрипта.
- `if … then … fi` и `for … do … done`.
- `read переменная` ждёт ввода.
- `exit 0` — успех, `exit 1` — ошибка.
