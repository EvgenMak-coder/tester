# Программа и процесс

Программа — это файл на диске. Процесс — это программа, которая запущена и работает прямо сейчас. Одну программу можно запустить несколько раз, и это будут разные процессы: три открытых окна терминала — три процесса `bash`.

У каждого процесса есть:

- **PID** — уникальный номер, который система выдаёт при запуске. По нему к процессу обращаются;
- **владелец** — пользователь, от имени которого процесс работает. От владельца зависят права процесса;
- **родитель** — процесс, который его запустил. Команда, набранная в терминале, становится потомком оболочки.

# Что сейчас запущено: ps

```
ps
ps aux
```

`ps` без ключей показывает только процессы текущего терминала — обычно саму оболочку и сам `ps`. Полный список всех процессов системы даёт `ps aux`.

В его выводе важнее всего несколько столбцов:

```
USER   PID %CPU %MEM COMMAND
anna  4242  1.5  3.2 /usr/bin/firefox
```

- `USER` — владелец;
- `PID` — номер процесса;
- `%CPU` и `%MEM` — доля процессора и памяти;
- `COMMAND` — чем процесс был запущен.

Список длинный, поэтому его обычно фильтруют:

```
ps aux | grep nginx
pgrep nginx
```

`pgrep` ищет процессы по имени и печатает только их номера. С ключом `-a` он добавляет к номерам командные строки.

# Наблюдать вживую: top

```
top
```

`top` показывает те же процессы, но обновляет экран каждые несколько секунд и ставит наверх тех, кто сильнее всех нагружает процессор. В первых строках — сводка по системе: сколько процессов, как заняты процессор и память.

Выход — клавиша `q`.

`ps` делает снимок на один момент и подходит для поиска процесса. `top` нужен, когда хочется увидеть, что происходит со временем.

# Прервать программу в терминале

Если программа запущена в терминале и работает слишком долго, её прерывают сочетанием **Ctrl+C**. Оно действует на ту программу, которая сейчас занимает терминал.

Похожие сочетания делают другое:

- Ctrl+D сообщает программе, что ввод закончился;
- Ctrl+Z не завершает, а приостанавливает программу;
- Ctrl+S замораживает вывод на экран до нажатия Ctrl+Q.

# Завершить по номеру: kill

Процесс, который не занимает ваш терминал, завершают по номеру:

```
kill 4242
```

Несмотря на грозное название, `kill` всего лишь отправляет процессу просьбу завершиться. Программа получает её, сохраняет данные, закрывает файлы и выходит. Файл программы на диске при этом никак не затрагивается.

Если искать номер не хочется, можно обратиться по имени:

```
pkill firefox
```

`pkill` отправит ту же просьбу всем процессам с таким именем.

Бывает, что программа зависла и на просьбу не реагирует. Для таких случаев есть принудительное завершение — `kill -9 4242`. Данные программа сохранить не успеет, поэтому это крайняя мера. Подробнее о ней — на среднем уровне.

# Чьи процессы можно завершать

Обычный пользователь может завершать только **свои** процессы. Попытка завершить чужой закончится отказом:

```
kill: (812): Operation not permitted
```

Чужие процессы, в том числе системные службы, может завершить только root:

```
sudo kill 812
```

# Запуск в фоне

Обычно терминал занят, пока программа работает. Знак `&` в конце команды запускает её в фоне, и приглашение возвращается сразу:

```
./backup.sh &
```

Оболочка ответит строкой вида `[1] 12345`: в квадратных скобках номер задания, за ним — PID.

```
jobs
fg %1
```

`jobs` показывает фоновые задания этого терминала. `fg %1` возвращает задание номер 1 на передний план: оно снова занимает терминал, и его можно прервать через Ctrl+C.

Две оговорки. Вывод фоновой программы по-прежнему идёт на экран и перемешивается с тем, что вы набираете. А при закрытии терминала фоновые задания обычно завершаются вместе с ним.

# Коротко

- Процесс — запущенная программа; у него есть номер (PID), владелец и родитель.
- `ps aux` — все процессы разом, `top` — живая картина, выход по `q`.
- `pgrep имя` находит номер процесса по имени.
- Ctrl+C прерывает программу в терминале.
- `kill PID` просит процесс завершиться; `pkill имя` — то же по имени.
- Завершать можно только свои процессы, чужие — через `sudo`.
- `команда &` запускает в фоне, `jobs` показывает задания, `fg` возвращает на передний план.
