# Учётная запись

Linux — многопользовательская система. Каждый, кто в ней работает, делает это под своей учётной записью, и от неё зависит, какие файлы он может открыть и какие команды выполнить. Учётные записи есть не только у людей: у большинства служб тоже своя, чтобы ошибка в одной программе не затронула остальные.

Учётная запись состоит из нескольких вещей:

- **имя** — то, что вы вводите при входе;
- **UID** — числовой номер. Система различает пользователей именно по нему, имя нужно людям;
- **основная группа**;
- **домашний каталог** — место для личных файлов, обычно `/home/имя`;
- **оболочка** — программа, которая запускается после входа, обычно `/bin/bash`.

# Кто я

```
whoami
id
```

`whoami` печатает имя текущего пользователя. `id` показывает больше: номер пользователя, основную группу и все группы, в которые он входит.

```
uid=1000(anna) gid=1000(anna) groups=1000(anna),27(sudo),998(docker)
```

По этим номерам система и решает, к чему у вас есть доступ.

# Суперпользователь root

Одна учётная запись особенная — **root**. На неё не действуют проверки прав: root может прочитать и изменить любой файл, завершить любой процесс, изменить любую настройку.

Особые права даёт не имя, а номер: у root UID равен 0. Домашний каталог у него тоже отдельный — `/root`, а не `/home/root`.

Обычные пользователи получают номера начиная с 1000. Номера меньше тысячи отведены служебным учётным записям.

# Файл /etc/passwd

Все учётные записи системы перечислены в файле `/etc/passwd`, по строке на каждую:

```
anna:x:1000:1000:Anna Petrova:/home/anna:/bin/bash
```

Поля разделены двоеточиями и идут в таком порядке:

1. имя;
2. `x` — заглушка на месте пароля;
3. UID;
4. номер основной группы;
5. описание, обычно полное имя;
6. домашний каталог;
7. оболочка.

Несмотря на название, паролей в этом файле нет. Читать его может любой пользователь, и многие программы так и делают: например, `ls -l` берёт из него имена владельцев.

В файле будет несколько десятков строк, хотя людей в системе один-два. Остальные — учётные записи служб: `www-data` для веб-сервера, `sshd` для сервера SSH и так далее.

# Группы

Группа — это набор пользователей. Она нужна, чтобы выдавать одинаковые права сразу нескольким людям: у файла есть группа и права для неё, и каждый участник группы получает эти права.

У пользователя одна основная группа и сколько угодно дополнительных.

```
groups
groups anna
```

Некоторые группы дают заметные возможности. Участникам группы `sudo` (в Fedora и RHEL — `wheel`) разрешено выполнять команды от имени root. Участники `docker` могут управлять контейнерами.

# Смена пароля

```
passwd
```

Команда без аргументов меняет пароль текущего пользователя. Сначала она спросит старый пароль, потом дважды новый.

> При вводе пароля в терминале ничего не отображается: ни символы, ни звёздочки. Это не зависание, просто печатайте и нажмите Enter.

root может сменить пароль кому угодно, назвав имя: `sudo passwd boris`. Старый пароль при этом не спрашивается.

# sudo

Работать под root постоянно опасно: любая опечатка действует на всю систему. Поэтому под ним обычно не входят, а выполняют отдельные команды с его правами:

```
sudo apt update
```

`sudo` спрашивает **ваш собственный** пароль, а не пароль root. Так он проверяет, что за клавиатурой именно тот, кому это разрешено. Пароль root знать не нужно; во многих системах он вообще не задан.

После успешного ввода `sudo` несколько минут не спрашивает пароль повторно.

Если вам `sudo` не разрешён, ответ будет таким:

```
anna is not in the sudoers file.
```

# Кто сейчас в системе

```
who
w
```

`who` перечисляет открытые сеансы: имя, терминал, время входа и адрес, с которого пользователь подключился. `w` добавляет к этому, чем каждый занят прямо сейчас.

# Коротко

- У учётной записи есть имя, номер (UID), основная группа, домашний каталог и оболочка.
- `whoami` — имя, `id` — номера и группы.
- root — пользователь с UID 0, на которого не действуют проверки прав; его каталог — `/root`.
- `/etc/passwd` — список учётных записей; паролей в нём нет.
- Группа даёт одинаковые права нескольким пользователям; список групп выводит `groups`.
- `passwd` меняет свой пароль; при вводе символы не видны.
- `sudo команда` выполняет одну команду от root и спрашивает ваш пароль.
- `who` и `w` показывают, кто вошёл в систему.
