# Регулярные выражения

До сих пор `grep` искал точный текст. Регулярное выражение описывает не конкретную строку, а её вид: «начинается с решётки», «заканчивается словом failed», «содержит число».

Основных знаков немного:

- `^` — начало строки;
- `$` — конец строки;
- `.` — один любой символ;
- `[abc]` — один символ из перечисленных, `[0-9]` — из диапазона, `[^0-9]` — любой, кроме перечисленных;
- `*` — предыдущий символ сколько угодно раз, в том числе ни разу.

```
grep '^#' sshd_config
grep 'failed$' auth.log
grep '^$' notes.txt
grep '[0-9][0-9]*' report.txt
```

Первая команда находит строки, начинающиеся с решётки, вторая — заканчивающиеся словом `failed`, третья — пустые, четвёртая — содержащие хотя бы одну цифру.

Чтобы найти сам особый знак, перед ним ставят обратную косую черту: `\.` — точка, `\$` — знак доллара.

> Шаблон берут в одинарные кавычки. Иначе оболочка сама попытается обработать `$`, `*` и скобки ещё до запуска `grep`.

Регулярные выражения легко спутать с шаблонами имён файлов. В `ls *.log` звёздочка значит «что угодно». В регулярном выражении она значит «повтор предыдущего символа», а «что угодно» записывается как `.*`.

# Ещё ключи grep

```
grep -r "TODO" src/
grep -v '^#' sshd_config
grep -c error app.log
grep -n error app.log
```

- `-r` обходит каталог со всеми подкаталогами. Перед каждой найденной строкой печатается имя файла.
- `-v` переворачивает поиск: выводятся строки, которые под шаблон **не** подходят. Вторая команда показывает файл настроек без закомментированных строк.
- `-c` считает подходящие строки, `-n` добавляет их номера.
- `-l` выводит только имена файлов, в которых что-то нашлось.
- `-w` ищет слово целиком: `grep -w log` не найдёт `login`.

Когда важно увидеть, что было вокруг найденной строки, помогают ключи контекста: `-A 3` покажет три строки после, `-B 3` — три строки до, `-C 3` — с обеих сторон.

# Вырезать поля: cut

Многие файлы состоят из полей с разделителем. В `/etc/passwd` это двоеточие:

```
anna:x:1000:1000:Anna Petrova:/home/anna:/bin/bash
```

`cut` вырезает нужные поля из каждой строки:

```
cut -d: -f1 /etc/passwd
cut -d: -f1,7 /etc/passwd
cut -c1-10 notes.txt
```

Ключ `-d` задаёт разделитель, `-f` — номера полей. Первая команда выведет список имён, вторая — имя и оболочку. Ключ `-c` работает не с полями, а с позициями символов.

У `cut` есть ограничение: разделитель — ровно один символ, и каждый такой символ начинает новое поле. Два пробела подряд он считает пустым полем между ними.

# Вырезать поля: awk

`awk` делит строку на поля по любому количеству пробелов и табуляций, поэтому подходит для выровненного вывода команд:

```
awk '{print $2}' report.txt
ps aux | awk '{print $2}'
awk -F: '{print $1}' /etc/passwd
```

`$1`, `$2` и так далее — поля по порядку, `$0` — строка целиком, `$NF` — последнее поле. Ключ `-F` задаёт другой разделитель.

Простое правило выбора: файл с чётким разделителем — `cut`, столбцы, выровненные пробелами, — `awk`.

# Заменить текст: sed

`sed` читает текст построчно и применяет к каждой строке команду. Самая частая — замена:

```
sed 's/http:/https:/' links.txt
sed 's/http:/https:/g' links.txt
```

Запись читается так: `s` — заменить, между косыми чертами — что искать и на что менять. Без буквы `g` в конце заменяется только первое совпадение в каждой строке, с ней — все.

Результат выводится на экран, сам файл остаётся прежним.

Ещё две полезные команды `sed`:

```
sed '/^#/d' sshd_config
sed -n '20,30p' app.log
```

Первая удаляет из вывода строки, начинающиеся с решётки. Вторая печатает строки с двадцатой по тридцатую: ключ `-n` отключает обычный вывод, а команда `p` печатает только указанный диапазон.

# Заменить символы: tr

`tr` работает не со строками, а с отдельными символами: заменяет каждый символ первого набора соответствующим символом второго.

```
tr 'a-z' 'A-Z' < names.txt
```

Имя файла `tr` не принимает, данные ему подают через перенаправление или конвейер.

# Посчитать повторы: sort и uniq

`uniq` убирает повторяющиеся строки, но сравнивает каждую только с предыдущей. Если одинаковые строки разбросаны по файлу, он их не заметит. Поэтому перед ним всегда стоит `sort`:

```
sort visitors.txt | uniq
sort visitors.txt | uniq -c
```

Ключ `-c` добавляет перед каждой строкой число её повторов. Добавив ещё одну сортировку, получают рейтинг:

```
sort visitors.txt | uniq -c | sort -rn | head
```

# Минимум vim

`vim` установлен почти везде, и рано или поздно вы в нём окажетесь: его открывают `git`, `crontab -e` и `visudo`. Главное, что нужно знать, — у него есть режимы.

- **Командный режим** включён сразу после открытия. Клавиши здесь — команды, а не буквы.
- **Режим вставки** включается клавишей `i`. Теперь можно печатать.
- **Esc** возвращает в командный режим.

Команды, начинающиеся с двоеточия, набирают в командном режиме и подтверждают клавишей Enter:

- `:w` — сохранить;
- `:q` — выйти;
- `:wq` — сохранить и выйти;
- `:q!` — выйти, не сохраняя правки.

Ещё три команды покрывают большинство мелких правок: `dd` удаляет строку, `u` отменяет последнее действие, `/слово` ищет.

Если не понимаете, в каком вы режиме, нажмите Esc несколько раз — окажетесь в командном.

# Коротко

- `^` — начало строки, `$` — конец, `.` — любой символ, `[…]` — один из набора, `*` — повтор предыдущего.
- Шаблоны для `grep` пишут в одинарных кавычках.
- `grep -r` ищет по каталогу, `-v` показывает неподходящие строки, `-c` считает, `-n` нумерует.
- `cut -d: -f1` — поля по одному разделителю; `awk '{print $2}'` — поля по пробелам.
- `sed 's/что/на что/g'` заменяет и печатает результат, файл не меняется.
- `uniq` видит только соседние повторы, поэтому сначала `sort`.
- В `vim`: `i` — печатать, Esc — назад, `:wq` — сохранить и выйти, `:q!` — выйти без сохранения.
