# Что такое inode

Файл в Linux состоит из трёх частей, которые хранятся отдельно.

- **Данные** — содержимое файла в блоках диска.
- **inode** — запись со сведениями о файле: тип, права, владелец, размер, отметки времени и то, где лежат данные.
- **Имя** — запись в каталоге, которая связывает строку с номером inode.

Главное здесь то, что имени в inode нет. Каталог — это просто таблица «имя → номер inode». Отсюда следует всё, что написано ниже о ссылках.

Номер inode показывает `ls -i`, а все сведения из него — команда `stat`:

```
ls -i notes.txt
stat notes.txt
```

# Жёсткие ссылки

Раз имя — лишь запись в каталоге, на один inode может указывать несколько имён. Второе имя создаёт команда `ln`:

```
ln notes.txt copy.txt
```

Теперь `notes.txt` и `copy.txt` — один и тот же файл под двумя именами. Они равноправны: «оригинала» среди них нет. Изменения, сделанные через одно имя, видны через другое.

В выводе `ls -l` число сразу после прав — счётчик имён:

```
-rw-r--r-- 2 anna anna 120 Oct  7 10:00 notes.txt
```

Команда `rm` убирает одно имя и уменьшает счётчик. Данные исчезают с диска, только когда счётчик доходит до нуля.

У жёстких ссылок два ограничения: их нельзя создать на каталог и нельзя провести между разными файловыми системами, потому что номера inode действуют только внутри своей.

# Символические ссылки

Символическая ссылка — отдельный маленький файл, в котором записан путь к цели:

```
ln -s /var/log/app/current.log app.log
```

В списке она помечена буквой `l` и стрелкой:

```
lrwxrwxrwx 1 anna anna 24 Oct  7 10:00 app.log -> /var/log/app/current.log
```

Такая ссылка может вести на каталог и на другой диск. Но она хранит только путь: если цель удалить или переименовать, ссылка останется и будет вести в никуда. Её называют битой.

- Жёсткая ссылка — ещё одно имя того же файла. Пока есть хоть одно имя, файл жив.
- Символическая ссылка — указатель на имя. Без цели она бесполезна.

# Шаблоны имён

Чтобы не перечислять файлы по одному, используют шаблоны. Оболочка сама заменяет шаблон списком подходящих имён.

- `*` — любое число любых символов, в том числе ни одного.
- `?` — ровно один любой символ.
- `[abc]` — один символ из перечисленных, `[0-9]` — один из диапазона.

```
ls *.log
ls log?.txt
ls report-202[3-5].pdf
```

Под `log?.txt` подойдут `log1.txt` и `logA.txt`, но не `log.txt` (на месте знака вопроса нет символа) и не `log10.txt` (их два).

Скрытые файлы под `*` не попадают: для них пишут `.*` явно.

# Поиск: find

`find` обходит каталог со всеми вложенными и отбирает файлы по условиям:

```
find /var/log -name '*.log'
find /var -type f -size +100M
find . -type d -name cache
find ~ -mtime -1
```

- `-name` — по имени. Шаблон берут в кавычки, чтобы его не раскрыла оболочка.
- `-type f` — обычные файлы, `-type d` — каталоги.
- `-size +100M` — больше 100 мегабайт; с минусом — меньше.
- `-mtime -1` — изменённые за последние сутки.

Условия, записанные подряд, должны выполняться все сразу.

# Место на диске: df и du

Две команды отвечают на два разных вопроса.

```
df -h
du -sh /var/log
du -h --max-depth=1 /var | sort -h
```

`df` показывает разделы целиком: размер, сколько занято, сколько свободно. `du` считает, сколько места занимает конкретный каталог со всем содержимым. Ключ `-h` выводит размеры в удобных единицах, `-s` — только итог.

Обычный порядок действий, когда место кончается: `df -h` показывает, какой раздел заполнен, затем `du` шаг за шагом находит, какой каталог его занял.

# Копирование как есть: cp -a

Обычный `cp -r` создаёт новые файлы: с текущим временем и с вами в роли владельца. Ключ `-a` (архив) сохраняет всё, что можно: права, владельцев, время изменения, а символические ссылки копирует как ссылки, а не как файлы, на которые они ведут.

```
sudo cp -a /etc/nginx /etc/nginx.backup
```

Этим ключом пользуются, когда копия должна заменить оригинал: при резервном копировании настроек и переносе данных.

# Что это за файл

Расширение в Linux ничего не гарантирует, а часто его нет вовсе. Команда `file` определяет тип по содержимому:

```
file data
```

Она ответит, например, `gzip compressed data` или `ASCII text`. Это первое, что стоит сделать со скачанным файлом без расширения.

# Коротко

- Имя, inode и данные хранятся отдельно; имя — это запись в каталоге.
- Жёсткая ссылка — второе имя того же inode. Символическая — файл с путём к цели.
- `*` — сколько угодно символов, `?` — ровно один.
- `find каталог условия` ищет по имени, типу, размеру и времени.
- `df` — свободное место на разделах, `du` — размер каталога.
- `cp -a` сохраняет права, владельцев и время.
- `file` определяет тип по содержимому.
