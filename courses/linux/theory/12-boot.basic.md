# Ядро

Слово «Linux» в строгом смысле означает **ядро** — программу, которая стоит между оборудованием и всеми остальными программами. Ядро распределяет процессорное время и память, управляет дисками, сетью и устройствами, следит за правами доступа.

Всё остальное — оболочка, команды вроде `ls`, графическая среда, службы — обычные программы, которые работают поверх ядра и обращаются к нему, когда им что-то нужно от оборудования.

```
uname -r
```

Команда печатает версию работающего ядра, например `6.8.0-45-generic`. С ключом `-a` она добавит имя компьютера, архитектуру и дату сборки.

# Что происходит при включении

Между нажатием кнопки питания и приглашением ко входу проходит четыре этапа.

1. **Прошивка материнской платы** — UEFI, на старых компьютерах BIOS. Она запускается первой, проверяет оборудование и находит диск, с которого грузиться.
2. **Загрузчик** — в Linux это обычно GRUB. Он показывает меню выбора системы, загружает в память ядро и передаёт ему управление.
3. **Ядро** определяет устройства, загружает драйверы и подключает корневую файловую систему.
4. **Первый процесс** — systemd. Он запускает службы и доводит систему до рабочего состояния.

Понимать этот порядок полезно по одной причине: по тому, на каком этапе всё остановилось, видно, где искать неполадку.

# Каталог /boot

Файлы, нужные для загрузки, лежат в `/boot`:

- `vmlinuz-…` — само ядро;
- `initrd.img-…` — вспомогательный образ, с которым ядро стартует;
- `grub/` — настройки загрузчика.

Ядер там обычно несколько: при обновлении старое остаётся на случай, если новое не заработает.

# Модули ядра

Ядро не держит в памяти драйверы всех существующих устройств. Большинство драйверов собрано **модулями** — частями ядра, которые подгружаются на ходу, когда найдено соответствующее устройство.

```
lsmod
```

Команда показывает модули, загруженные сейчас. Подключили флешку — загрузился модуль для неё; отдельно ничего ставить не пришлось.

# Сообщения ядра: dmesg

Ядро ведёт собственный журнал: что за устройства найдены, какие драйверы загружены, какие ошибки возникли.

```
sudo dmesg
sudo dmesg -T | tail
```

Сюда смотрят в первую очередь, когда не определяется диск, флешка или сетевая карта. Ключ `-T` заменяет секунды от загрузки обычным временем, а `tail` оставляет свежие сообщения. Подключите устройство и сразу выполните команду — последние строки расскажут, что ядро о нём думает.

# Сколько система работает

```
uptime
```

Команда выводит текущее время, сколько система работает с момента загрузки, число вошедших пользователей и среднюю нагрузку. Серверы работают месяцами, и по этому числу сразу видно, была ли недавно перезагрузка.

# Перезагрузка и выключение

```
sudo reboot
sudo poweroff
sudo shutdown -h now
sudo shutdown -r +10
```

- `reboot` — перезагрузить;
- `poweroff` — выключить;
- `shutdown -h now` — выключить немедленно. Ключ `-h` означает остановку, `-r` — перезагрузку;
- вместо `now` можно указать время: `+10` — через десять минут. Вошедшие пользователи получат предупреждение. Отменяет запланированное `shutdown -c`.

Все эти команды сначала корректно останавливают службы и записывают данные на диск. Выключать сервер кнопкой или питанием нельзя: недописанные файлы останутся повреждёнными.

> На удалённом сервере перезагрузка обрывает ваше соединение. Прежде чем её выполнить, убедитесь, что нужные службы включены в автозапуск, иначе после загрузки они не поднимутся.

# Коротко

- Ядро управляет оборудованием, памятью и процессами; его версию показывает `uname -r`.
- Порядок загрузки: прошивка (UEFI) → загрузчик (GRUB) → ядро → systemd.
- Ядро и файлы загрузчика лежат в `/boot`.
- Модули — подгружаемые части ядра, обычно драйверы; список — `lsmod`.
- `dmesg` показывает сообщения ядра об устройствах и ошибках.
- `uptime` — время работы с загрузки.
- `reboot` перезагружает, `poweroff` и `shutdown -h now` выключают.
