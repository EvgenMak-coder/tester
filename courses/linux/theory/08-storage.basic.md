# Диски как файлы

В Linux устройства представлены файлами в каталоге `/dev`. Диск — тоже файл, и по его имени понятно, что это за устройство.

- `/dev/sda` — первый диск, `/dev/sdb` — второй и так далее.
- `/dev/sda1`, `/dev/sda2` — первый и второй **разделы** диска `sda`.
- `/dev/nvme0n1` — диск NVMe, а `/dev/nvme0n1p1` — его первый раздел.

Раздел — это часть диска, которая ведёт себя как отдельное устройство. Один диск обычно разбит на несколько разделов: под систему, под данные, под подкачку.

# Что подключено: lsblk

```
lsblk
```

Команда рисует дерево: диски, разделы на них, размеры и то, куда каждый подключён.

```
NAME   SIZE TYPE MOUNTPOINT
sda    100G disk
├─sda1   1G part /boot
└─sda2  99G part /
sdb     16G disk
└─sdb1  16G part /mnt/usb
```

Прав root для этого не нужно. С этой команды начинают любую работу с дисками, чтобы не перепутать устройства.

# Файловая система

Сам по себе раздел — просто последовательность байтов. Чтобы хранить на нём файлы и каталоги, на разделе создают **файловую систему**: она определяет, как данные и их имена укладываются на диск.

В Linux чаще всего используют **ext4** — надёжную файловую систему, принятую по умолчанию в Debian и Ubuntu. В Fedora и RHEL обычно ставят XFS. На флешках для совместимости с другими системами встречаются FAT32 и exFAT, а NTFS — родная файловая система Windows.

# Что значит смонтировать

В Linux нет букв дисков. Чтобы файлы раздела стали доступны, его **монтируют** — подключают к какому-нибудь каталогу единого дерева. Этот каталог называют точкой монтирования.

```
sudo mount /dev/sdb1 /mnt/usb
```

Первый аргумент — что подключаем, второй — куда. После команды содержимое флешки видно в `/mnt/usb`. Данные никуда не копируются: каталог становится входом в файловую систему раздела.

Сам каталог должен существовать заранее. Принятые места: `/mnt` для ручного подключения и `/media`, куда графическая среда монтирует съёмные носители сама.

# Отключить перед извлечением

```
sudo umount /mnt/usb
```

Команда пишется без буквы n: `umount`.

> Запись на диск идёт с задержкой: данные сначала попадают в память. `umount` дожидается, пока всё будет записано. Вынутая без него флешка может остаться с неполными файлами.

Если `umount` отвечает «target is busy», значит какая-то программа ещё работает с файлами раздела. Чаще всего это сам терминал, в котором вы находитесь внутри этого каталога: достаточно выйти из него командой `cd`.

# Сколько осталось места

```
df -h
```

`df` показывает каждую смонтированную файловую систему: размер, сколько занято, сколько свободно и где она подключена. Ключ `-h` выводит размеры в гигабайтах и мегабайтах.

```
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda2        98G   61G   33G  66% /
/dev/sdb1        16G  2.1G   14G  14% /mnt/usb
```

Строк будет больше: среди них служебные файловые системы вроде `tmpfs`, которые живут в памяти.

# Память и подкачка

```
free -h
```

`free` показывает оперативную память и подкачку — к дискам относится только вторая строка.

**Подкачка** (swap) — место на диске, куда система вытесняет данные из оперативной памяти, когда её не хватает. Она позволяет пережить нехватку памяти, не завершая программы. Но диск намного медленнее памяти, поэтому система, которая активно пользуется подкачкой, заметно тормозит.

В выводе `free` самый полезный столбец — `available`: сколько памяти реально доступно программам.

# Коротко

- Диски лежат в `/dev`: `sda` — диск, `sda1` — его первый раздел.
- `lsblk` показывает диски, разделы и точки монтирования.
- Файловая система определяет, как файлы хранятся на разделе; в Linux обычно ext4.
- Смонтировать — подключить раздел к каталогу: `mount устройство каталог`.
- Перед извлечением — `umount`, без буквы n.
- `df -h` — свободное место на дисках, `free -h` — память и подкачка.
