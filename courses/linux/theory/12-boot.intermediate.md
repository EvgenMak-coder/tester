# Загрузка по шагам

Цепочка загрузки — это передача управления от одной программы к следующей. У каждого звена своя задача.

1. **UEFI** проверяет оборудование и запускает загрузчик с загрузочного диска.
2. **GRUB** читает свои настройки, показывает меню, загружает в память два файла — ядро и initramfs — и передаёт ядру строку параметров.
3. **Ядро** запускается, распаковывает initramfs и использует его, чтобы добраться до настоящего корневого раздела.
4. **systemd** стартует с корневого раздела как первый процесс и запускает всё остальное.

# Зачем нужен initramfs

У ядра есть проблема курицы и яйца. Чтобы подключить корневой раздел, нужен драйвер диска. А драйверы лежат на корневом разделе.

Корень к тому же бывает устроен сложно: на LVM, на программном RAID, на зашифрованном разделе, на сетевом хранилище. Для каждого случая нужны свои модули и программы.

**initramfs** — небольшая временная файловая система, которую загрузчик кладёт в память рядом с ядром. В ней собрано всё необходимое, чтобы найти и подключить настоящий корень: модули, программы для LVM и расшифровки. Сделав это, ядро переключается на настоящий корень, и initramfs больше не нужен.

Образ создаётся под конкретное ядро и лежит в `/boot` рядом с ним.

# Настройка GRUB

У GRUB два файла, и важно не перепутать, какой из них править.

- `/boot/grub/grub.cfg` — то, что GRUB читает при загрузке. Этот файл создаётся автоматически, и ручные правки в нём пропадут при следующем обновлении ядра.
- `/etc/default/grub` — настройки, из которых первый файл собирается. Править нужно его.

```
GRUB_TIMEOUT=5
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
```

Первая строка задаёт, сколько секунд показывать меню, вторая — параметры, которые будут переданы ядру.

После правки настройки нужно собрать заново, иначе ничего не изменится:

```
sudo update-grub
```

В Fedora и RHEL то же делает `sudo grub2-mkconfig -o /boot/grub2/grub.cfg`.

# Параметры ядра

Загрузчик передаёт ядру строку параметров. Они определяют, где корневой раздел и как себя вести при загрузке:

```
cat /proc/cmdline
```

```
BOOT_IMAGE=/vmlinuz-6.8.0-45-generic root=UUID=3f1c9a2e-… ro quiet splash
```

- `root=` — где корневая файловая система;
- `ro` — сначала подключить её только для чтения;
- `quiet` — не показывать сообщения ядра на экране;
- `splash` — показывать графическую заставку.

Файл `/proc/cmdline` отвечает на вопрос, с какими параметрами загружена система прямо сейчас. Так проверяют, подействовала ли правка `/etc/default/grub`.

# Работа с модулями

```
lsmod
modinfo e1000e
sudo modprobe e1000e
sudo modprobe -r e1000e
```

- `lsmod` — что загружено сейчас;
- `modinfo` — сведения о модуле: описание, путь к файлу, параметры, которые он принимает. Загружать модуль для этого не нужно;
- `modprobe имя` — загрузить модуль;
- `modprobe -r имя` — выгрузить.

Есть ещё команда `insmod`. Она загружает ровно тот файл, который ей указали, и завершается ошибкой, если не хватает зависимостей. `modprobe` находит модуль по имени в `/lib/modules` и сначала загружает всё, от чего он зависит. Поэтому на практике пользуются `modprobe`.

Чтобы модуль загружался при каждом старте, его имя записывают в файл в каталоге `/etc/modules-load.d/`.

# Параметры ядра на ходу: sysctl

Многие настройки ядра можно менять у работающей системы, без перезагрузки. Для этого служит `sysctl`:

```
sysctl net.ipv4.ip_forward
sudo sysctl -w net.ipv4.ip_forward=1
```

Первая команда читает параметр, вторая меняет. Изменение действует сразу, но **только до перезагрузки**: `sysctl -w` ничего никуда не записывает.

Чтобы значение применялось при каждой загрузке, его кладут в файл в каталоге `/etc/sysctl.d/`:

```
net.ipv4.ip_forward = 1
```

Имя файла обычно начинается с числа, которое задаёт порядок: `99-local.conf`. Применить все файлы без перезагрузки можно командой:

```
sudo sysctl --system
```

Правило то же, что у команды `ip` и у `mount`: команда действует сейчас, файл — всегда.

# Коротко

- GRUB загружает ядро и initramfs; ядро подключает корень и запускает systemd.
- initramfs — временная система в памяти с драйверами для доступа к корню.
- Настройки GRUB правят в `/etc/default/grub`, затем `sudo update-grub`.
- `/proc/cmdline` — параметры, с которыми загружено ядро.
- `modprobe` загружает модуль вместе с зависимостями, `modinfo` показывает сведения о нём.
- `sysctl -w` меняет параметр до перезагрузки; постоянные значения — в `/etc/sysctl.d/`.
