# Одно дерево каталогов

В Linux нет дисков C: и D:. Все файлы всех дисков собраны в одно дерево, которое начинается с корневого каталога. Он обозначается косой чертой: `/`.

Каталоги первого уровня есть в любой системе, и у каждого своё назначение. Запоминать все сразу не нужно, достаточно основных:

- `/home` — домашние каталоги пользователей: `/home/anna`, `/home/boris`. Здесь лежат ваши файлы.
- `/etc` — настройки системы и программ.
- `/var` — данные, которые меняются при работе: журналы, кэши, очереди.
- `/tmp` — временные файлы. Система вправе их удалять.
- `/bin` и `/usr` — программы.
- `/root` — домашний каталог суперпользователя. Он лежит отдельно от `/home`.

# Где я нахожусь

В каждый момент оболочка находится в одном каталоге — текущем. Узнать его и сменить позволяют две команды:

```
pwd
cd /etc
```

`pwd` печатает полный путь к текущему каталогу. `cd` переходит в другой. Команда `cd` без аргументов возвращает в домашний каталог.

# Абсолютные и относительные пути

Путь — это адрес файла или каталога. Записать его можно двумя способами.

**Абсолютный путь** начинается с косой черты и отсчитывается от корня: `/home/anna/docs/report.txt`. Он означает одно и то же, где бы вы ни находились.

**Относительный путь** начинается не с косой черты и отсчитывается от текущего каталога. Если вы в `/home/anna`, то `docs/report.txt` — тот же самый файл.

В относительных путях используют три сокращения:

- `.` — текущий каталог;
- `..` — каталог уровнем выше, родительский;
- `~` — домашний каталог.

```
cd ..
cd ../boris
cd ~/docs
cd -
```

Последняя строка, `cd -`, возвращает в каталог, где вы были перед этим.

# Что лежит в каталоге

```
ls
ls -l
ls -a
```

`ls` выводит имена файлов. С ключом `-l` показывает подробности: права, владельца, размер, время изменения. С ключом `-a` добавляет скрытые файлы.

Скрытым в Linux считается любой файл, имя которого начинается с точки, например `.bashrc`. Отдельного свойства «скрытый» нет, это просто соглашение об именах: в таких файлах программы хранят свои настройки, чтобы они не мешались в обычном списке.

# Создание

```
mkdir projects
mkdir -p projects/site/css
touch notes.txt
```

`mkdir` создаёт каталог. Ключ `-p` создаёт сразу всю цепочку вложенных каталогов и не считает ошибкой те, что уже есть. `touch` создаёт пустой файл, если его не было.

# Копирование и перенос

```
cp notes.txt backup.txt
cp -r projects projects-old
mv notes.txt docs/
mv old.txt new.txt
```

`cp` копирует: сначала указывают, что копировать, потом — куда. Для каталогов нужен ключ `-r`, без него `cp` их пропускает.

`mv` и переносит, и переименовывает: для системы это одно и то же действие. Если последний аргумент — существующий каталог, файл переедет в него. Если нет — получит новое имя.

> И `cp`, и `mv` молча заменяют файл, если на месте назначения уже есть файл с таким именем. Ключ `-i` заставляет их спрашивать подтверждение.

# Удаление

```
rm notes.txt
rm -r projects-old
rmdir empty
```

`rm` удаляет файлы. Каталог вместе с содержимым удаляет `rm -r`. Команда `rmdir` удаляет только пустые каталоги и потому безопасна.

# Чем опасно удаление

В командной строке **нет корзины**. Удалённое командой `rm` вернуть нельзя: ни сочетанием клавиш, ни отдельной командой.

Несколько привычек, которые берегут от потерь:

- Перед `rm` с шаблоном выполните `ls` с тем же шаблоном и посмотрите, что под него попадает.
- Проверяйте пробелы. `rm -r old /` вместо `rm -r old/` — это попытка удалить всю систему.
- Не добавляйте ключ `-f` по привычке: он отключает вопросы и сообщения об ошибках.
- Пока учитесь, пользуйтесь `rm -i`: команда спросит про каждый файл.

# Коротко

- Дерево каталогов одно и начинается с `/`.
- Абсолютный путь начинается с косой черты, относительный отсчитывается от текущего каталога.
- `.` — текущий каталог, `..` — родительский, `~` — домашний.
- `ls -l` — подробности, `ls -a` — вместе со скрытыми файлами.
- `cp -r` копирует каталоги, `mv` переносит и переименовывает.
- `rm` удаляет навсегда: корзины нет.
