# Почему всё держится на тексте

В Linux почти всё — обычный текст: настройки программ, журналы, вывод команд. Поэтому большая часть повседневной работы сводится к четырём действиям: посмотреть файл, найти в нём нужное, посчитать и поправить. Для каждого есть своя маленькая программа.

# Вывести целиком: cat

```
cat notes.txt
cat -n notes.txt
cat part1.txt part2.txt
```

`cat` печатает файл на экран целиком. Ключ `-n` добавляет номера строк. Если назвать несколько файлов, они будут выведены подряд, один за другим.

Для коротких файлов этого достаточно. Длинный файл пролетит по экрану, и на нём останется только конец.

# Листать: less

```
less /var/log/syslog
```

`less` открывает файл для просмотра по одному экрану. Файл при этом не загружается целиком, поэтому даже гигабайтный журнал открывается мгновенно.

Клавиши, которых хватает на каждый день:

- стрелки и PageUp/PageDown — листать;
- пробел — на экран вперёд, `b` — на экран назад;
- `g` — в начало файла, `G` — в конец;
- `/слово` — искать вперёд, `n` — следующее совпадение;
- `q` — выйти.

Страницы руководства `man` показываются через `less`, поэтому клавиши там те же.

# Начало и конец: head и tail

```
head access.log
head -n 5 access.log
tail -n 20 access.log
```

`head` показывает начало файла, `tail` — конец. Без ключей обе выводят десять строк, другое число задаёт ключ `-n`.

В журналах самое свежее находится в конце, поэтому `tail` нужен постоянно. У него есть особенно полезный режим:

```
tail -f app.log
```

С ключом `-f` команда не завершается, а ждёт и показывает новые строки по мере их появления. Так наблюдают за журналом, пока в соседнем окне воспроизводят ошибку. Выход — Ctrl+C.

# Найти строки: grep

```
grep error app.log
```

`grep` печатает те строки файла, в которых встретился заданный текст. Сам файл он не меняет.

Четыре ключа стоит запомнить сразу:

- `-i` — не различать заглавные и строчные буквы: найдутся и `Error`, и `ERROR`;
- `-n` — показывать номер строки перед каждой найденной;
- `-c` — вместо строк вывести их количество;
- `-v` — наоборот, показать строки, в которых текста нет.

Если в искомом тексте есть пробелы, его берут в кавычки:

```
grep -i "connection refused" app.log
```

Искать можно сразу в нескольких файлах: `grep error *.log`. Тогда перед каждой строкой будет указано, из какого она файла.

# Посчитать: wc

```
wc -l users.csv
wc users.csv
```

`wc -l` выводит число строк. Без ключей `wc` печатает три числа: строки, слова и байты.

Чаще всего `wc -l` ставят в конец конвейера, чтобы посчитать то, что вывела другая команда:

```
grep error app.log | wc -l
ls | wc -l
```

# Отсортировать: sort

```
sort names.txt
sort -r names.txt
sort -n sizes.txt
```

`sort` выводит строки файла по алфавиту. Ключ `-r` переворачивает порядок, `-n` сортирует как числа, а не как текст, `-u` убирает повторяющиеся строки.

> Ни одна из этих команд не меняет файл. `cat`, `grep`, `sort` и остальные читают его и печатают результат на экран.

Чтобы сохранить результат, вывод перенаправляют в другой файл:

```
sort names.txt > sorted.txt
```

В тот же самый файл перенаправлять нельзя: оболочка очистит его раньше, чем `sort` успеет прочитать. Для этого у `sort` есть ключ `-o`: `sort -o names.txt names.txt`.

# Поправить: редактор nano

```
nano notes.txt
```

`nano` — самый простой редактор в терминале: открыли и сразу печатаете. Если файла не было, он будет создан при сохранении.

Внизу экрана всегда видны подсказки. Знак `^` в них означает клавишу Ctrl.

- Ctrl+O — сохранить. `nano` покажет имя файла, его подтверждают клавишей Enter.
- Ctrl+X — выйти. Если есть несохранённые правки, `nano` спросит, записать ли их.
- Ctrl+W — искать.
- Ctrl+K — вырезать строку, Ctrl+U — вставить её.

Системные файлы открывают с `sudo`: `sudo nano /etc/hosts`. Без него редактор откроет файл, но сохранить не сможет.

# Коротко

- `cat` — вывести файл целиком, `less` — листать, выход по `q`.
- `head` и `tail` — начало и конец, по умолчанию десять строк; `tail -f` следит за файлом.
- `grep текст файл` — найти строки; `-i` без учёта регистра, `-n` с номерами, `-c` посчитать, `-v` наоборот.
- `wc -l` считает строки.
- `sort` сортирует: `-n` как числа, `-r` в обратном порядке.
- Эти команды только читают файл; результат сохраняют через `>` в другой файл.
- В `nano` Ctrl+O сохраняет, Ctrl+X выходит.
