# Терминал и оболочка

Терминал — это окно, в котором вводят текст. Оболочка — программа, которая этот текст читает: разбирает строку, находит нужную программу, запускает её и показывает результат. В большинстве дистрибутивов оболочкой служит bash.

Оболочка сообщает о готовности приглашением:

```
anna@laptop:~$
```

Здесь `anna` — имя пользователя, `laptop` — имя компьютера, `~` — текущий каталог (тильда означает домашний). Знак `$` в конце говорит, что вы обычный пользователь. У суперпользователя root вместо него стоит `#`.

# Как устроена команда

Команда — это строка из слов, разделённых пробелами:

```
ls -l /etc
```

- `ls` — **программа**, которую нужно запустить. Она всегда стоит первой.
- `-l` — **ключ**. Он меняет поведение программы: здесь включает подробный вывод.
- `/etc` — **аргумент**. Он говорит, с чем работать: здесь — какой каталог показать.

Ключей и аргументов может быть несколько, а может не быть вовсе: просто `ls` покажет текущий каталог.

Ключи бывают двух видов. Короткие состоят из одного дефиса и одной буквы, и их можно писать слитно: `ls -la` — то же самое, что `ls -l -a`. Длинные начинаются с двух дефисов и пишутся целым словом: `ls --all`. Часто у одного ключа есть обе формы.

Некоторым ключам нужно значение. Оно идёт сразу после ключа:

```
head -n 5 notes.txt
```

Здесь `5` относится к ключу `-n` — «показать пять строк».

> Регистр букв важен везде: в именах программ, ключах и именах файлов. `-r` и `-R` — разные ключи, а `Notes.txt` и `notes.txt` — разные файлы.

# Где искать справку

Помнить все ключи не нужно. У каждой программы есть встроенная справка двух видов.

```
man ls
ls --help
```

`man` открывает полное руководство. Листать его можно стрелками и пробелом, искать — набрав `/` и слово, выйти — клавишей `q`. Ключ `--help` печатает краткую сводку прямо в терминал и сразу возвращает приглашение.

Есть исключение: команды, встроенные в саму оболочку, например `cd`. Отдельной программы у них нет, и справку по ним даёт `help cd`.

# Tab и история

Две привычки, которые экономят больше всего времени.

**Клавиша Tab** дописывает начатое имя команды или файла. Наберите `cd /etc/sys` и нажмите Tab — оболочка допишет имя, если вариант один. Если вариантов несколько, второе нажатие Tab покажет их список. Заодно это проверка: если Tab ничего не дописал, такого файла нет.

**История** хранит всё, что вы вводили.

- Стрелка вверх возвращает предыдущие команды по одной.
- `history` выводит пронумерованный список.
- `!42` повторяет команду под номером 42.
- Ctrl+R ищет по истории: нажмите и начните набирать любую часть команды.

# Вывод в файл

Обычно программа печатает результат на экран. Знак `>` отправляет его в файл:

```
ls -l /etc > list.txt
```

На экране ничего не появится, а в `list.txt` окажется список. Если файла не было, он будет создан.

> Одиночный `>` сначала стирает файл и только потом пишет. Прежнее содержимое пропадает без предупреждения.

Чтобы дописать в конец, не трогая того, что уже есть, используют два знака:

```
echo "проверка пройдена" >> log.txt
```

# Соединение команд

Команды можно связывать тремя способами.

**Конвейер** — вертикальная черта. Он передаёт вывод левой команды на вход правой:

```
ls | wc -l
```

`ls` печатает имена по одному в строке, `wc -l` считает строки. Получается число файлов в каталоге. Так из маленьких программ собирают сложные действия.

**Двойной амперсанд** запускает вторую команду, только если первая завершилась успешно:

```
mkdir build && cd build
```

Если каталог создать не удалось, `cd` не выполнится.

**Точка с запятой** просто выполняет команды по очереди, что бы ни случилось с первой:

```
date; ls
```

# Коротко

- Команда — это программа, ключи и аргументы, разделённые пробелами.
- Короткие ключи пишутся слитно: `-la`. Длинные — с двумя дефисами: `--all`.
- Справка: `man программа` и `программа --help`.
- Tab дополняет имена, стрелка вверх и `history` возвращают прошлые команды.
- `>` записывает вывод в файл, стирая его; `>>` дописывает в конец.
- `|` передаёт вывод следующей команде, `&&` запускает её только при успехе, `;` — в любом случае.
