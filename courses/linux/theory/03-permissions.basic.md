# Зачем нужны права

Linux с самого начала рассчитан на то, что компьютером пользуются несколько человек и десятки программ одновременно. Права доступа определяют, кто может читать файл, кто — изменять, а кто — запускать. Благодаря им один пользователь не может испортить файлы другого, а ошибка в обычной программе не ломает систему.

# Владелец, группа и остальные

У каждого файла и каталога есть **владелец** — один пользователь, и **группа** — один набор пользователей. Права задаются отдельно для трёх категорий:

- **владелец** файла;
- участники **группы** файла;
- **остальные** — все, кто не попал в первые две категории.

Обычно владельцем становится тот, кто создал файл.

# Три права

Прав тоже три, и у каждого своя буква:

- `r` (read) — читать содержимое;
- `w` (write) — изменять содержимое;
- `x` (execute) — запускать файл как программу или скрипт.

Удаление и переименование в этот список не входят. Они зависят не от прав файла, а от прав каталога, в котором он лежит.

# Как читать вывод ls -l

```
-rwxr-x--- 1 anna dev 2048 Oct  7 10:00 backup.sh
```

Первый символ — тип: дефис означает обычный файл, `d` — каталог, `l` — символическую ссылку.

Следующие девять символов — права, три тройки подряд:

```
rwx   r-x   ---
```

Первая тройка относится к владельцу, вторая — к группе, третья — к остальным. Буква означает, что право есть, дефис на её месте — что его нет.

Дальше в строке идут число ссылок, имя владельца (`anna`), группа (`dev`), размер и время изменения.

Этот файл читается так: anna может читать, изменять и запускать; участники группы dev — читать и запускать; остальные не могут ничего.

# Числовая запись

Те же права часто записывают тремя цифрами. У каждого права свой вес:

- `r` = 4
- `w` = 2
- `x` = 1

Цифра для категории — сумма весов её прав:

- `rwx` = 4 + 2 + 1 = 7
- `rw-` = 4 + 2 = 6
- `r-x` = 4 + 1 = 5
- `r--` = 4
- `---` = 0

Три цифры идут в том же порядке: владелец, группа, остальные. Права из примера выше — `rwxr-x---` — это 750.

Несколько значений встречаются постоянно:

- **644** (`rw-r--r--`) — обычный файл: владелец правит, остальные читают;
- **755** (`rwxr-xr-x`) — программа или каталог, доступные всем;
- **600** (`rw-------`) — личный файл, например ключ SSH;
- **700** (`rwx------`) — личный каталог.

# chmod: изменить права

Права меняет команда `chmod`. Ей можно дать число:

```
chmod 750 backup.sh
chmod 644 notes.txt
```

или сказать, что добавить и что убрать:

```
chmod +x install.sh
chmod go-w notes.txt
```

Первая строка добавляет право на запуск. Вторая отнимает право записи у группы (`g`) и остальных (`o`); владелец обозначается буквой `u`.

Самая частая ситуация — скачанный или только что написанный скрипт не запускается:

```
bash: ./install.sh: Permission denied
```

У новых файлов права на исполнение нет. Его добавляет `chmod +x install.sh`.

Менять права файла может только его владелец и root.

# chown: сменить владельца

```
sudo chown alice notes.txt
sudo chown alice:dev notes.txt
```

До двоеточия пишут владельца, после — группу. Сами права `rwx` при этом не меняются. Передать файл другому пользователю может только root, поэтому команда обычно идёт с `sudo`.

# root и sudo

В системе есть особый пользователь — **root**, суперпользователь. Проверки прав на чтение и запись на него не действуют: он может открыть и изменить любой файл.

Именно поэтому под root не работают постоянно. Вместо этого отдельные команды выполняют с его правами через `sudo`:

```
sudo nano /etc/hosts
```

`sudo` спросит ваш собственный пароль, выполнит одну команду от имени root и вернёт вас в обычный режим. Так остаётся видно, какие именно действия потребовали особых прав, а случайная опечатка в остальных командах не затронет систему.

# Коротко

- У файла есть владелец и группа. Права задаются для владельца, группы и остальных.
- `r` — читать, `w` — изменять, `x` — запускать.
- В `ls -l` три тройки идут по порядку: владелец, группа, остальные.
- В числах r = 4, w = 2, x = 1; цифры складываются.
- `chmod` меняет права, `chown` — владельца и группу.
- Скрипт не запускается с «Permission denied» — нужен `chmod +x`.
- root не подчиняется проверкам; отдельные команды от его имени выполняют через `sudo`.
